About this site

A personal, per-character daily and weekly task tracker for AION 2 (Global). It is a plain web page: no accounts, no backend, nothing to install.

Please read

  • Unofficial fan project. It is not affiliated with, endorsed by or related to NCSoft or any website or creator it links to. AION is a trademark of NCSoft.
  • The information can be wrong or out of date. Task details come from public community guides and from NCSOFT patch notes, and the game changes often. Confirm important numbers in game. Every source is credited in SOURCES.md, and the links on the tracker point to the original sites.
  • Made for a casual player. I built it for myself to keep track of my characters. It is not meant to be a complete or authoritative guide.

Your data

  • Everything you tick or edit is saved only in your own browser (local storage). Nothing is sent to a server, and I cannot see it.
  • It stays on that browser and that site address. Clearing site data, or using another browser or device, starts you from scratch.
  • Use Settings → Export JSON to back it up or move it to another device, and Import to restore it.

Resets and times

  • The game resets daily at 07:00 UTC and weekly on Wednesday at 07:00 UTC, the same moment on every Global server. A task counts as done until that moment passes.
  • In Settings you can pick your server region and server. This sets the server clock and the event times (Spacetime Rift, Shugo Festival and the others) shown in the timeline, and it never moves the real reset. Event times follow a community schedule, not an official one.
  • Live server status is not shown here. The tracker links to status pages run by other sites.

Removal requests

If you own a site or video that is linked here and want it removed, message me through github.com/alioh or open an issue, and I will take it down.

Contribute

Anyone can contribute: fixes to task data, better guides and code improvements are welcome. The source is on GitHub; open an issue or a pull request. The README explains how to run it locally and how to edit the task list.

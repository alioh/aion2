# Task icons

Put your own image for a task in this folder and it shows next to the task title.

**Name the file after the task id**, in `png`, `svg`, `webp` or `jpg` (a square image, about 64x64 or larger, works best):

| `invasion-key.png` | Dimensional Invasion reward key |
| `daily-dungeon.png` | Daily Dungeon (Unknown Fissure) |
| `ascension-trial.png` | Ascension Trial |
| `exploration.png` | Exploration (Expedition dungeons) |

**Tasks you add yourself:** name the file after the title in lowercase with dashes, for example `my-task.png` for a task called "My task".

If there is no file, the task shows the small map icon (if it has a map layer) or no icon.

Only add images you have the right to use. This repository is public, so anything you put here is published with it.
